Hi everyone! 🌱

The latest patch introduced a bug that caused character references to be lost in dialogues when editing and saving a character.

This patch fixes that issue and includes a check that attempts to **automatically restore lost character references** when opening a dialogue file.

Sorry for the inconvenience! 😢
