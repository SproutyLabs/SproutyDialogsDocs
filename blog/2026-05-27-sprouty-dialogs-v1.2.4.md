## What's Changed

---

- Fix resources release issue to reuse DialogPlayer in [#70](https://github.com/SproutyLabs/SproutyDialogs/pull/70), reported in [#69](https://github.com/SproutyLabs/SproutyDialogs/issues/69) by @BriceN and in [#77](https://github.com/SproutyLabs/SproutyDialogs/issues/77) by @Moumekie
- Add `PackedScene` autoload method calls by @migmoog in [#72](https://github.com/SproutyLabs/SproutyDialogs/pull/72), reported in [#71](https://github.com/SproutyLabs/SproutyDialogs/issues/71)
- Fix the order in which a portrait enters to the scene when is inside a DialogBox in [#73](https://github.com/SproutyLabs/SproutyDialogs/pull/73)
- Auto update autoload and method list on Call Method Node in [#74](https://github.com/SproutyLabs/SproutyDialogs/pull/74)
- Auto update portrait list in Dialogue Nodes when character change in [#75](https://github.com/SproutyLabs/SproutyDialogs/pull/75)
- Auto update all variable fields when variables are saved in [#76](https://github.com/SproutyLabs/SproutyDialogs/pull/76)
- Auto update start IDs from external dialogue file in Jump To Node in [#78](https://github.com/SproutyLabs/SproutyDialogs/pull/78)
