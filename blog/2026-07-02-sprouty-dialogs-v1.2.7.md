Hi everyone! 🌱

Many bug fixes, and now the editor remembers your workspace! 📁

<!-- truncate -->

## What's Changed

---

- Add property to prevent input propagation in DialogBox by @Kazymila in [#106](https://github.com/SproutyLabs/SproutyDialogs/pull/106), reported by @deuxsoto in [#102](https://github.com/SproutyLabs/SproutyDialogs/issues/102)
- Allow dialogue and comment nodes vertical resizing by @deuxsoto in [#107](https://github.com/SproutyLabs/SproutyDialogs/pull/107)
- Make comment node's text wrap at its boundaries by @deuxsoto in [#108](https://github.com/SproutyLabs/SproutyDialogs/pull/108)
- Make file list selection and context menu behave like Godot script editor by @deuxsoto in [#110](https://github.com/SproutyLabs/SproutyDialogs/pull/110)
- Round size and offset values in nodes to prevent changes when zooming by @Kazymila in [#113](https://github.com/SproutyLabs/SproutyDialogs/pull/113), reported by @deuxsoto in [#111](https://github.com/SproutyLabs/SproutyDialogs/issues/111)
- Fix crash when using multiple portraits of the same character by @Kazymila in [#104](https://github.com/SproutyLabs/SproutyDialogs/pull/114), reported by @chesterblack in [#112](https://github.com/SproutyLabs/SproutyDialogs/issues/112)
- Restore opened Sprouty files at startup by @Kazymila in [#115](https://github.com/SproutyLabs/SproutyDialogs/pull/115), suggested by @deuxsoto in [#101](https://github.com/SproutyLabs/SproutyDialogs/issues/101)
